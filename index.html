LOCAL ENCRYPTION

Key milikmu. Perangkatmu.

API Key dienkripsi dengan AES-GCM menggunakan kunci turunan PBKDF2. Kata sandi brankas tidak disimpan oleh aplikasi.

  • Key tidak dikirim ke server AI DRAMA STUDIO.
  • Key hanya dikirim ke provider terpilih saat kamu menjalankan permintaan.
  • Hapus data browser atau kehilangan kata sandi dapat membuat key tidak bisa dipulihkan.
  • Enkripsi lokal tidak melindungi key dari malware, ekstensi berbahaya, atau orang yang menguasai perangkat dan sesi browser.
Penting

Untuk keamanan akun, buat API Key khusus aplikasi dengan batas penggunaan jika provider menyediakan fitur tersebut. Jangan gunakan key utama dengan akses berlebihan.

GETTING STARTED

Panduan penggunaan

Mulai menggunakan AI Drama Studio.

01. Pilih provider

Buka menu AI & API Key. Pilih OpenAI, Google Gemini, atau Kie.ai. Hanya satu provider aktif pada satu waktu.

02. Simpan API Key

Masukkan API Key dan buat kata sandi brankas lokal. Key dienkripsi dan disimpan pada browser/perangkat ini.

03. Pilih model

Masukkan model ID yang tersedia untuk API dan akunmu. Nama model dapat berubah mengikuti provider.

04. Buat brief drama

Isi ide cerita, genre, durasi, jumlah scene, target penonton, lalu generate.

05. Simpan dan ekspor

Hasil dapat disimpan di proyek lokal, disalin, atau diunduh sebagai TXT. Backup proyek secara berkala.

Catatan browser

Permintaan langsung ke API pihak ketiga dapat dibatasi oleh CORS. Jika browser menolak koneksi, aplikasi client-only tidak bisa mengatasinya sendiri tanpa proxy/backend yang dikonfigurasi oleh pemilik API.
